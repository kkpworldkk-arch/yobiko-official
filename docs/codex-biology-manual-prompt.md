# Codex への依頼（第3弾）：標準セミナー生物基礎を作り直す（章＋種類＋番号で選べるように）

化学230選と同じ方法（PDF を目で見て手入力し、採点の基準も保存する）で、「標準セミナー生物基礎 2021」を作り直してください。進め方とルールは `docs/codex-chemistry-manual-prompt.md` と同じです。この文書には、違う点だけを書きます。

**この依頼文は、以前の生物の依頼（「要点の一問一答」「SEC:」を使う版）を置き換えます。** まとめページの赤字から一問一答を作る作業は保留になりました。SEC: は使いません。

## 背景
今の生物基礎の問題（1021問）は、作り直しが必要な状態です。
- 本の問題ではなく、まとめページの文章から AI が作った問題が多い。
- 無作為に30問を調べたところ、約4割に、答えの誤り・問いと答えのずれ・図がないと答えられない問題があった。
- 本の問題番号も保存されていない。

この本は、各章が「まとめ → プロセス（1問1答）→ 基本例題 → 基本問題 → 標準例題 → 標準問題」の順に並んでいます。**問題番号は、章ごと・種類ごとに 1 から振り直されています。** 巻末には「特集 演習問題」があります。

## 2. 取り込みスクリプト
`scripts/import-chemistry-230.mjs` をもとに、参考書を指定できる汎用の `scripts/import-manual-book.mjs` を新しく作ってください。
- **使い方の例**：`node scripts/import-manual-book.mjs data/manual-import/biology-seminar-2021.txt --book "標準セミナー生物基礎 2021" --dry-run`
- **`import-chemistry-230.mjs` は消さない**：利用者が本番でこのファイルを使う手順を持っています。中身は、新しいスクリプトを化学の設定で呼ぶだけでかまいません。化学のテンプレートが今までと同じ結果で取り込めることを確認してください。
- **`TYPE:` を読み取る**：`TYPE:` があるテンプレートに対応させてください。保存先は、新しい列 `problem_type TEXT NOT NULL DEFAULT ''` です。`src/lib/db.ts` の `ensureColumn` で追加します。
- **重複チェック**：同じ問題が2回入っていないかは、(章, 種類, 番号, 小問) の組み合わせで確かめてください。習熟度の引き継ぎも、同じ組み合わせで照合します。
- **番号の範囲チェック**：番号の上限は、化学では230のまま、生物では指定しない（1以上の整数ならよい）。
- **並び順**：`order_index` は、テンプレートに書いた順（本の掲載順）にしてください。

## 3. アプリ側の変更：章 → 種類 → 番号の順に選べるようにする
利用者の要望は「**問題番号を選ぶときに、章と問題番号を選べるようにする**」ことです。

### 出題範囲の画面（`src/app/student/oral-exam/page.tsx`）
`problem_type` を持つ問題がある本では、次の順で選べるようにしてください。
1. **章**：1つを選ぶ。「すべての章」も選べる。
2. **種類**：プロセス／基本例題／基本問題／標準例題／標準問題／演習問題。選んだ章に実在する種類だけを出す。「すべての種類」も選べる。
3. **問題番号の範囲**：「○番〜○番」。選んだ章・種類に実在する番号だけを出す。

**組み合わせによる動き**
- 章と種類の両方を選んだときだけ、番号の範囲を選べるようにする。番号が章ごとに重複するので、章と種類が決まらないと番号が一意にならないためです。
- 章と種類を選び、番号を選ばない場合は、その章・その種類の全問を出す。

**`problem_type` が無い本**（化学・黄チャート・英単語など）
- 今の画面と動作をそのまま保つこと（化学は「問題番号 1〜230」で選べる今の形のまま）。

### 絞り込みの処理
- `src/lib/db.ts` の `OralExamQuestionFilters` に `problemType` を追加し、`matchesOralExamFilters` で章・種類・番号の AND 条件で絞り込んでください。
- 選択肢のデータを作る `getOralExamFilterOptions` は、`{ 章: { 種類: [番号...] } }` の形で、章ごと・種類ごとの番号一覧を返すようにしてください。

### 表示
- 出題中の画面と回答履歴では、「第1章 基本問題 9 問2」のように、章・種類・番号・小問を表示する。
- 講師画面の問題一覧でも、同じ形で表示する。
